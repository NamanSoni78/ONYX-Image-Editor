   - Use `use client` directive ONLY at the lowest necessary component level
   - NEVER make a page-level component a Client Component
   
→ Streaming & Suspense for SEO:
   - Use Suspense boundaries around Client Components
   - The fallback content should be SEO-meaningful (not just a spinner)
   - Googlebot will see the initial Server Component HTML + Suspense fallbacks
   - Example: The editor tool loads in a Suspense boundary, but the H1, description, FAQs, and all text content are Server Components that render instantly

→ How to verify SEO rendering:
   - curl the page and check the HTML contains all SEO content
   - Google Search Console URL Inspection tool
   - View Source vs. Inspect Element comparison
   - Googlebot user agent testing
   
→ The /editor page special case:
   - The editor itself is a heavy Client Component (Canvas API, WebGL, etc.)
   - But the PAGE must still have SSR shell with SEO content
   - Pattern: Server Component page with Client Component editor embedded
   - The editor loads inside <Suspense fallback={<EditorSkeleton />}>
   - EditorSkeleton contains SEO text about the editor
